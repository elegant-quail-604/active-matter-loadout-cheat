# Active Matter Loadout Toolkit — feature reference

Use the Active Matter loadout toolkit workspace to move between equipment groups, session profiles, and reference notes. The section map below gives each part a clear place in the project.

| Section | Description |
|---|---|
| Equipment groups | Equipment categories and the associated selection or configuration options. |
| Session profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Reference notes | A dedicated section for reference notes and the configuration details associated with that area. |

The project page follows the same section structure.
